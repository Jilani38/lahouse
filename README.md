# LA HOUSE · Pass VIP

Compte à rebours des cartes Pass VIP de la famille LA HOUSE (BDE Ametra).

- `zacharie/` : la page du QR code de Zacharie
- `leonard/` : la page du QR code de Léonard
- `assets/config.js` : la date de fin du compte à rebours (heure de Paris)

Ne pas renommer le dépôt ni les dossiers `zacharie/` et `leonard/` : les QR codes imprimés pointent dessus.
